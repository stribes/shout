# Shout

A tiny anonymous message wall for everyone.

I was looking for new domains for my project [Sable](https://github.com/sablelabs-de/sable) when I stumbled across a Russian website called [sable.one](https://sable.one). I liked the idea, so I decided to rebuild it for fun!

Shout is a litttttle experiment in anonymous, real-time messaging. Just a place to leave a message and see what everyone else has to say.

## Public instance

You can try it out at [shout.striberry.de](https://shout.striberry.de).
